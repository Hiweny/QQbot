# QQBot AI - 纯前端机器人

> 无需服务器，浏览器中运行的 QQ 机器人。支持群聊/私聊/频道，内置 AI 对话、长期记忆、自动摘要、多供应商切换，并且**持续保活**，适合开发者快速搭建个人 AI 助手。

## ✨ 功能特色

- 🚀 **纯前端**：仅需一个 HTML 文件，打开即用，所有数据保存在浏览器本地（IndexedDB + localStorage）。
- 🤖 **QQ 机器人接入**：基于腾讯官方 API（WebSocket + REST），支持群聊（`GROUP_AT_MESSAGE_CREATE`）、私聊（`C2C_MESSAGE_CREATE`）、频道（`AT_MESSAGE_CREATE`）。
- 🧠 **AI 对话引擎**：
  - 默认内置**免费公益 API**（无需密钥）
  - 支持任何 **OpenAI 兼容接口**（DeepSeek、智谱、Ollama 等），可自由添加多个供应商并切换
- 💬 **智能上下文管理**：
  - 可配置上下文窗口（轮数）
  - 长期记忆：超窗自动 AI 摘要，形成结构化记忆（事实陈述），支持手动/自动两种模式
- 📱 **手机 / 桌面自适应**：响应式 UI，触屏优化，底部导航。
- 🔋 **后台保活**：
  - WebSocket 自动重连（指数退避）
  - 屏幕常亮锁（Wake Lock API）
  - 定期 Ping 防止后台休眠
  - 切回前台自动检测连接状态
  - 浏览器通知（提升页面活跃度）
- 🔐 **安全配置**：AppID / AppSecret 仅存本地，Token 自动续期。
- 📊 **会话管理**：按对话分组，查看历史消息、记忆条目，支持一键删除/总结。

## 📦 快速开始

### 1️⃣ 获取 QQ 机器人凭证
1. 前往 [QQ 开放平台](https://q.qq.com/) 创建机器人应用。
2. 记录 **AppID** 和 **AppSecret**。
3. 若机器人处于开发阶段，请开启 **沙箱模式**（默认开启），沙箱下只响应测试频道/群。

### 2️⃣ 打开页面
- 直接下载 `QQBot-Web.html` 用浏览器打开（推荐 Chrome / Edge）。
> 在线体验：[QQBot AI 纯前端机器人](https://hiweny.github.io/QQbot/)

### 3️⃣ 填写配置
- 点击底部 **「⚙️ 设置」**：
  - 填入 AppID 和 AppSecret。
  - 确认沙箱模式开关（新机器人建议打开）。
  - 检查 AI 供应商：默认已有一个免费公益站，无需额外配置即可使用。如需自己的 API，可点击 **「添加槽位」** 填写 Base URL、API Key 和模型名，然后点 **「选中」** 切换。

### 4️⃣ 启动机器人
- 回到 **「🏠 状态」** 页，点击 **「🚀 启动机器人」**。
- 页面将请求屏幕常亮权限（允许后防止手机锁屏断连）。
- 等待连接成功，状态显示 **「已连接」** 即代表上线。

### 5️⃣ 测试对话
- 在绑定的 QQ 群/私聊中 @机器人（或直接私聊），机器人将自动回复。
- 所有会话记录和记忆将持久保存在浏览器中，关闭页面重新打开仍然保留。

## ⚙️ 配置详解

### 机器人凭据
| 字段 | 说明 |
|------|------|
| AppID | 开放平台应用 ID |
| AppSecret | 应用密钥（仅本地存储，不会上传） |
| 沙箱模式 | 开启后仅在测试频道/群生效，正式上线请关闭 |

### AI 供应商
支持两种类型：
- **🆓 免费公益站**：内置免费 API（无需 Key），但有请求频率限制，适合体验。
- **🔷 OpenAI 兼容**：任意兼容 OpenAI Chat Completion 接口的服务，例如：
  - DeepSeek (`https://api.deepseek.com/v1`)
  - 智谱 AI (`https://open.bigmodel.cn/api/paas/v4`)
  - Ollama 本地 (`http://localhost:11434/v1`)
  - 其他任何 `v1/chat/completions` 端点

> 每个供应商可独立配置名称、Base URL、模型名、API Key，并支持随时切换。

### 机器人行为开关
| 开关 | 作用 |
|------|------|
| ⏰ 注入当前时间 | 在系统提示词中自动插入当前日期时间，让 AI 感知实时时间 |
| 🧠 长期记忆 | 当上下文超出窗口时，自动调用 AI 生成摘要并存入记忆库 |
| 💬 自动分段 | 长回复自动拆分为多条消息发送（QQ 单条消息有长度限制） |
| 👥 回复群聊 | 是否响应群聊中的 @ 消息 |
| ✉️ 回复私聊 | 是否响应私聊消息 |
| 上下文窗口 | 保留最近 N 轮对话作为上下文，轮数越多消耗 token 越多 |

### 高级功能
- **手动总结**：在「会话」页可一键总结所有会话，或进入单个会话手动总结当前对话。
- **诊断工具**：状态页的「🔍 诊断」可全面检测网络连通性、CORS、WebSocket、AI 接口等。
- **Token 兜底**：若自动获取失败，可手动粘贴临时 Token（有效 2 小时）。

## 🗄️ 数据持久化

所有数据均存储在浏览器本地：
- **配置**：`localStorage`（键 `qqbot_cfg`）
- **消息历史、记忆、会话列表**：IndexedDB（数据库名 `QQBotDB`）

> ⚠️ 清除浏览器缓存/ IndexedDB 将丢失所有数据和配置，请谨慎操作。

## 🧪 已知限制 & 注意事项

- **CORS 问题**：QQ 官方 API 不支持浏览器跨域请求，代码内置了多个代理（`cors.sh`、`api.allorigins.win`、`corsproxy.io`）作为备选。若代理不可用，请手动配置本地代理或使用浏览器插件（如 CORS Unblock）。
- **WebSocket 连接**：需要稳定的网络环境，若长时间后台运行可能被系统限制，建议保持页面可见或开启通知权限。
- **免费公益 API**：稳定性无法保证，如遇服务不可用请切换至自己的供应商。
- **安全性**：AppSecret 和 API Key 明文存储在浏览器中，仅供个人测试使用，请勿用于生产环境或分享页面给他人。
